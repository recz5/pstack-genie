# Architecture playbook

1. State the goals, non-goals, operational constraints, and acceptance criteria.
2. Inspect current architecture and interfaces rather than assuming a greenfield system.
3. Draw the relevant data/control flow in plain language.
4. Evaluate two realistic alternatives when tradeoffs are material.
5. Recommend an approach with explicit costs, risks, security boundaries, and failure modes.
6. If authorized, implement a minimal proof in a non-production environment.
7. Verify the design using tests or measurable evidence, and record unresolved assumptions.
