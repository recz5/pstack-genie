# Feature playbook

1. Define intended user-visible outcome and acceptance tests.
2. Name the core data shapes, contracts, trust boundaries, and dependencies.
3. Inspect patterns already used by the project.
4. Choose the simplest viable design and implement in verifiable units.
5. Add tests that cover behavior, failure modes, and authorization boundaries.
6. Verify the result in a safe environment and summarize deploy requirements.

Do not convert a feature request into permission to deploy.
