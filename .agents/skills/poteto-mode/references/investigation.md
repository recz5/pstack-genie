# Investigation playbook

1. Identify the question and what evidence could disprove the initial hypothesis.
2. Discover permitted sources: code, schemas, logs, deployment config, tests, documentation.
3. Inspect primary evidence rather than infer from names or summaries.
4. Reconstruct relevant state and data flows, noting uncertain boundaries.
5. Cross-check the central claim against another observable fact where feasible.
6. Answer with findings, evidence, alternatives, limitations, and a next action only when useful.

Read-only by default. Do not execute DDL, DML, deployments, or permission changes merely to answer a question.
