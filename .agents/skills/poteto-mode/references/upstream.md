## Upstream pstack

This project adapts Lauren Tan's pstack for
Databricks Genie Code.

The original pstack source is not bundled
with the installed poteto-mode skill.

The GitHub repository may contain:
- scripts/import_upstream.py
- vendor/pstack/
- vendor/UPSTREAM.txt

These are repository maintenance resources,
not runtime dependencies.

poteto-mode can operate without them.
