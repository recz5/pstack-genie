# Performance playbook

1. Define the workload, metric, time window, and baseline environment.
2. Identify actual bottlenecks with available query profiles, logs, or traces.
3. Form one falsifiable hypothesis at a time.
4. Change a single relevant factor in a safe test environment.
5. Compare before/after measurements using equivalent inputs and conditions.
6. Explain confounders and distinguish observed wins from estimates.

Never claim a speedup based on rewritten SQL alone.
